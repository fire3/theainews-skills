# Style System

一次出图封面不是模板：每篇文章先选风格，再选版式，两者各自按防重复规则
轮换出稿。**版式决定构图骨架，风格决定配色与字体气质**——只有风格变而
版式不变，封面上看起来仍然千篇一律。本文件是风格与版式选择的唯一依据。

## 选择规则（优先级从高到低）

1. **用户显式指定**：请求中出现风格名或 `--style <name>` → 直接使用。
2. **栏目映射**：
   - models → `dark-atmospheric` 或 `bold-editorial`
   - tools → `editorial-infographic` 或 `blueprint`
   - research → `scientific` 或 `blueprint`
   - industry → `bold-editorial` 或 `corporate`
   - tutorial → `sketch-notes` 或 `editorial-infographic`
3. **防重复**：查看最近 3 张封面（`public/covers/*.jpg` 修改时间，或
   `prompts/` 历史），若栏目首选风格刚用过，改用备选；若备选也用过了，
   按下方风格池顺序取第一个未用过的风格。
4. **强调色轮换**：同风格相邻出现时（跨栏目无法避免），轮换该风格的
   强调色变体，保证观感不同。
5. **版式选择与轮换**：风格确定后，从下方「版式池」挑一套版式。
   - 严禁连续两张封面使用同版式；最近 3 张封面（`prompts/` 历史或
     `public/covers/*.jpg` 修改时间）用过的版式不要立刻再用。
   - **不要默认回落到「底部三张卡片」**：只有当最近 3 张都用了其他版式、
     且这个版式与本文内容确实匹配时才可选它。
   - 每份提示词头部同时记录 `风格 + 版式`（如 `scientific + left-text-right-visual`），
     便于防重复检查。

## 禁止事项

- 严禁无脑使用深海军蓝 + 青/紫——那是 `dark-atmospheric` 一个风格的选择。
- 严禁连续两张封面同风格（除非用户点名）。
- 风格决定配色与字体气质；不要在同一张封面混搭两种风格。

---

## 版式池（构图骨架，绝不固定）

版式与风格正交：任何风格都可以配任意版式。出稿时先定版式，再用所选风格的
背景/排版/配色/视觉元素填充。以下为当前版式池，优先级从上到下。

### L-hero-center — 居中主视觉
- 构图：品牌字标小字在左上；主标题居中偏上大字；视觉主体铺满画面中央/背景作
  氛围，副标题嵌在主标题下方一行。
- 信息承载：不用统计卡片行，数据点融入标题/副标题或散点标注，避免等距三卡。
- 适用：产品发布、模型发布（models）、重磅消息。

### L-left-text-right-visual — 左文右图
- 构图：左栏（约 40%）品牌 + 标题 + 副标题 + 少量要点竖排；右栏（约 60%）
  满幅抽象视觉（硬件/流程/图表隐喻）。
- 信息承载：要点用 2–3 个短句竖排，不排卡片行。
- 适用：教程、工具解读、架构（tutorial、tools）。

### L-big-number — 大数字杂志
- 构图：画面中央一个超大数字/短关键词（如「8GW」「3」）即视觉核心，标题文字
  与数字结合或被数字吸走；副标题一行。
- 信息承载：一个核心数字撑满主体，其余事实只留 1–2 行，不排三卡。
- 适用：单点数据强的消息（容量、版本号、指标）。

### L-split-panel — 分栏叙事
- 构图：左右或上下硬切分栏（斜切/水平），一栏纯视觉/色块，一栏承载文字；
  事实按栏组织（如时间线、对比上下两行），不要求等距三卡。
- 信息承载：用分栏或时间线呈现 2–3 个事实。
- 适用：对比、变革叙事、行业事件（industry、research）。

### L-bottom-cards — 底部三卡（原默认，作为备选）
- 构图：品牌左上 + 居中标题 + 副标题 + 底部等距 2–3 张统计卡片。
- 仅当最近 3 张封面均非本版式、且数据确实适合表格化时才使用；严禁连用。

## 版式选择自查
- 最近 3 张封面版式分别是什么？当前选的版式是否与它们重复？
- 是否又悄悄回到「标题 + 底部三卡」？若是，换一套。
- 版式与风格匹配、与文章信息形态匹配（单点数据→大数字；多步骤→左文右图/
  分栏；单条重磅→居中）。

## dark-atmospheric

- 气质：电影感深色科技编辑风，深海军蓝渐变 + 克制的青/紫辉光
- 背景：#0A0A0A → #1A1A2E 渐变，细网格 + 轻雾
- 排版：粗体无衬线纯白标题；浅灰副文字（#A0AEC0）
- 配色：白 #FFFFFF / 浅灰 #A0AEC0 / 青 #06B6D4 / 紫 #8B5CF6 / 深灰 #2D3748
- 视觉：发光几何硬件、数据流与节点、径向辉光
- Do：高对比、克制的光效、几何精确
- Don't：过曝霓虹、低对比文字、明亮背景
- 变体 A：青色为主；变体 B：紫色为主
- 栏目：models、产品发布

## bold-editorial

- 气质：高对比深色杂志风，戏剧化排版 + 单一高饱和强调色
- 背景：深炭黑 #0D0D0D，可带大片色块或斜切分区
- 排版：超大粗体标题，可斜体/衬线点缀
- 配色：白 #FFFFFF / 炭黑 #0D0D0D / 强调色（珊瑚 #FF4D4D 或 琥珀 #FFB020 或 青绿 #00E0A8）
- 视觉：杂志式大数字、色块、切片、粗描边图形
- Do：强对比、大胆留白、单一强调色
- Don't：元素过密、多强调色混用
- 变体 A：珊瑚红；变体 B：琥珀黄；变体 C：青绿
- 栏目：industry、重大发布

## editorial-infographic

- 气质：浅色杂志编辑风，白底 + 结构化信息图
- 背景：纯白 #FFFFFF + 浅灰 #F8F9FA 面板
- 排版：粗体现代无衬线近黑标题，正文深灰
- 配色：近黑 #1A1A1A / 深灰 #4A5568 / 编辑蓝 #2563EB / 珊瑚 #F97316 / 翠绿 #10B981
- 视觉：扁平图标、流程箭头、面板/卡片、数据高亮
- Do：杂志级精致、结构化布局、充足留白
- Don't：照片、深色满版背景、过密
- 变体 A：蓝色为主；变体 B：珊瑚色为主
- 栏目：tools、解读、教程

## blueprint

- 气质：工程蓝图风，网格底 + 精密线条
- 背景：蓝图米白 #FAF8F5 + 浅灰网格 #E5E5E5
- 排版：工程感无衬线标题；优雅衬线正文
- 配色：深板岩 #334155 / 工程蓝 #2563EB / 藏蓝 #1E3A5F / 浅蓝 #BFDBFE / 琥珀 #F59E0B
- 视觉：90 度折线、尺寸标注、截面图、正交投影
- Do：一致线宽、网格对齐、克制配色
- Don't：手绘曲线、装饰、照片
- 变体 A：蓝色为主；变体 B：琥珀点缀为主
- 栏目：research、架构、系统

## scientific

- 气质：冷色严谨学术风，清晰数据导向
- 背景：白/浅灰 #F8F9FA，可带细分隔线
- 排版：技术感无衬线，标题粗、标签细
- 配色：深蓝灰 #1E293B / 蓝 #2563EB / 青 #06B6D4 / 琥珀 #F59E0B
- 视觉：图表、坐标轴、节点示意图、标注框
- Do：数据准确可视化、克制、清晰层级
- Don't：装饰性元素、夸张渐变
- 栏目：research、评测

## corporate

- 气质：商务专业风，藏蓝 + 金
- 背景：藏蓝 #0F1B33 或白底 + 藏蓝分区
- 排版：几何无衬线，标题粗、稳重
- 配色：藏蓝 #0F1B33 / 金 #C9A227 / 白 #FFFFFF / 灰 #64748B
- 视觉：简洁图表、卡片、数据块
- Do：秩序感、稳定配色、大量留白
- Don't：手绘、荧光色、随意排版
- 栏目：industry、商业

## minimal

- 气质：极简中性，大面积留白 + 单个强调色
- 背景：纯白 #FFFFFF 或近黑 #111111
- 排版：无衬线，字重对比强烈，字距宽松
- 配色：近黑 #111111 / 浅灰 #9CA3AF / 单强调色（青 #06B6D4 或 橙 #F97316 或 绿 #10B981）
- 视觉：极少图形，重点数字超大
- Do：留白、单一焦点、克制
- Don't：装饰堆积、多色
- 栏目：综述、简报、观点

## sketch-notes

- 气质：暖色手绘教育风，亲和
- 背景：暖米白 #FFF8EC，轻微纸纹
- 排版：手写感标题、圆润文字
- 配色：墨褐 #4A2C17 / 暖橙 #E8751A / 草绿 #7FB069 / 奶油 #FFF8EC
- 视觉：手绘图标、箭头、涂鸦框、便签
- Do：温暖、可亲、有机线条
- Don't：完美几何、冷色科技感
- 栏目：tutorial、教育、入门
